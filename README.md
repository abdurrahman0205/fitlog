## About the Project 
FitLog is a simple fitness workout management web app where users can explore workouts, view workout details, create a daily workout plan, save workouts, and track their progress.

---

## Project Overview  

- Explore different workouts
- View detailed workout information
- Create and manage a daily workout plan
- Save your favorite workouts
- Track your workout progress
- Sort workouts based on different options



---

## Key Features  

- Workout Plan Management
- Live Workout Statistics 
- Workout Library
- Workout Progress Tracking
- Responsive and user friendly interface

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/abdurrahman0205/fitlog.git
```

2. Go to the project folder:

```bash
cd fitlog
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```

5. Open `http://localhost:3000` in your browser.
